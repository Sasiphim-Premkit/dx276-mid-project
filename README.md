# ห้องคราฟต์ของเรา — เกมทายนิสัยสาย DIY & Craft

ไฟล์ในโฟลเดอร์นี้
- `index.html` — ตัวเกมทั้งหมด (แบบทดสอบ 10 ข้อ → การ์ดตัวละคร → ใส่รูป+ชื่อ → ห้องคราฟต์เรียลไทม์)
- `supabase-setup.sql` — สคริปต์สร้างฐานข้อมูลเรียลไทม์

ถ้าเปิด `index.html` โดยยังไม่ตั้งค่า Supabase เกมจะเข้าโหมดทดลอง มีเพื่อนจำลองให้ดูหน้าตาห้อง

## ขั้นที่ 1 — สร้างฐานข้อมูลเรียลไทม์ (Supabase, ฟรี)
1. สมัครที่ https://supabase.com แล้วกด New project (เลือก Region: Singapore)
2. เข้าเมนู SQL Editor วางเนื้อหาไฟล์ `supabase-setup.sql` แล้วกด Run
3. เข้า Project Settings > API คัดลอก Project URL และ anon public key
4. เปิด `index.html` แก้ 2 บรรทัดนี้ด้านบนของส่วน `<script>`
   ```js
   const SUPABASE_URL = "https://xxxx.supabase.co";
   const SUPABASE_ANON_KEY = "eyJhbGciOi...";
   ```

## ขั้นที่ 2 — ขึ้น Vercel
วิธีง่ายสุด: เข้า https://vercel.com/new แล้วลากโฟลเดอร์นี้ไปวาง (หรือ push ขึ้น GitHub แล้ว Import)
ไม่ต้องตั้งค่า Build อะไร เพราะเป็นเว็บแบบ static

หรือใช้ CLI
```
npm i -g vercel
vercel --prod
```

## ใช้งานวันจริง
- ลิงก์ผู้เล่น: `https://ชื่อเว็บ.vercel.app/?room=workshop1`
- ลิงก์ผู้จัด (มีปุ่ม "ล้างห้อง"): `https://ชื่อเว็บ.vercel.app/?room=workshop1&host=1`
- เปลี่ยนรหัสห้องได้ทุกรอบ เช่น `room=รอบเช้า` `room=รอบบ่าย` คนจะไม่ปนกัน
- เอาลิงก์ไปทำ QR Code ขึ้นจอให้ผู้เล่นสแกน
- ตัวละครทุกตัวเดินเล่นเองรอบโต๊ะ บางทีเดินไปแซวเพื่อน หรือแวะโต๊ะอื่น
- ผู้เล่นแตะพื้นเพื่อพาตัวเองเดิน ทุกคนในห้องจะเห็นเดินไปตำแหน่งเดียวกันแบบเรียลไทม์
- คนที่ปิดแท็บไปจะกลายเป็นสีเทา กลับมาเปิดลิงก์เดิมจะเข้าห้องเดิมได้ทันที

40 คนอยู่ในขีดจำกัดของ Supabase แพ็กเกจฟรีสบาย ๆ (รองรับการเชื่อมต่อพร้อมกัน 200 คน)

## โหมดต่อสู้ (เป่ายิงฉุบ กรรไกร ค้อน กระดาษ)
- ผู้จัดเปิดลิงก์ที่มี `&host=1` แล้วกด "เข้าดูแบบผู้จัด" (เหมาะกับเปิดขึ้นจอโปรเจกเตอร์) หรือจะเล่นด้วยก็ได้
- กดปุ่ม "⚔️ เริ่มสู้ 3 นาที" ทุกเครื่องในห้องจะเริ่มนับถอยหลังพร้อมกัน
- แตะตัวเพื่อนต่างสายเพื่อท้าสู้ ทั้งคู่มีเวลาเลือก 8 วินาที เสมอกันต้องเลือกใหม่ ใครไม่ออกมือถือว่าแพ้
- ผู้ชนะได้ +1 คะแนนให้สายของตัวเอง ผู้แพ้กลายเป็นผี 👻 แล้วเกิดใหม่ในอีก 5 วินาที
- หมดเวลาจะประกาศสายที่ชนะเป็น "สุดยอดสายงานคราฟต์" พร้อม MVP คนที่ชนะมากที่สุด
- หน้าจอของผู้จัดเป็นตัวจับเวลาและคะแนนกลาง จึงควรเปิดค้างไว้ตลอดรอบ (อย่ารีเฟรชระหว่างสู้)

## เสียง
- มีเพลงประกอบ 2 เพลง (ในห้องคราฟต์ และตอนสู้) กับเอฟเฟกต์เสียงทุกจังหวะ สังเคราะห์สดในเบราว์เซอร์ ไม่ต้องมีไฟล์ ไม่ติดลิขสิทธิ์
- ปุ่ม 🔊 / 🔇 ใช้เปิดปิดเสียง เครื่องจะจำค่าไว้
- ถ้าอยากใช้เพลงของตัวเอง วางไฟล์ .mp3 ไว้ในโฟลเดอร์เดียวกัน แล้วใส่ชื่อไฟล์ที่ `BGM_ROOM_URL` และ `BGM_BATTLE_URL`

## ปรับแต่ง
ใน `index.html` แก้ได้ที่
- `CHARS` — ชื่อตัวละคร คำโปรย ค่าพลัง และคำพูดกวน ๆ ในห้อง (`{o}` = ชื่อเพื่อนที่สุ่มมา)
- `BATTLE_MS`, `PICK_MS`, `RESPAWN_MS` — เวลาต่อรอบ เวลาเลือกอาวุธ และเวลาเกิดใหม่ (มิลลิวินาที)
- `QUESTIONS` — คำถามและคะแนนที่แต่ละคำตอบให้กับตัวละคร
